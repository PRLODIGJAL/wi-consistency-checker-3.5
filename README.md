# WI 一致性检验工具 v3.5

把 PDF 版作业指导书（WI）里的规格参数，和要导入 MES 的 Excel 采集项**逐条自动核对**，对不上的连「第几页、哪一行」列出来；双击一行，右侧直接展开 PDF 原图，点格子就能校正。**免装 Python，拷到哪都能用。**

## 为什么做

MES 系统维护要导入 Excel 采集数据，源头是 PDF 版 WI 里的规格参数表。原来的做法是「照着 PDF 人工敲进 Excel，再人工复核一遍」，中间没有任何机器把关。

单份 WI 有数百到一千余行参数，人工逐条核对约 **0.5 小时**；复核同样靠人眼，疲劳后照样会漏；一旦错填、漏填进 MES，往往要到下游环节才暴露。

现在单份 **19 秒**出结果。

## 这个仓库里有什么 / 没有什么

只放**源码**（`app/`）与说明书。

- **没有 `runtime/`**：3.0 起是「免装交付」版，完整发布包自带 Python 运行时（单平台 113 MB）与离线 wheels（20 MB），超过 GitHub 单文件限制，也不该进版本库。要真正运行，自己补一个 Python 3.13 环境即可（依赖清单见 `app/shell/setup_env.py`）。
- **没有 `data/`**：运行期产物（词库、锚点、上次选择、历史快照），首次启动自动创建。
- **没有 `dev/`**：调试脚本、历史快照与语料。

## 功能

- **10 种 PDF 版式**自动识别：竖表、横表、步骤在列、正文散文、简表 KV、表头 KV、英文横表、矩阵表、程序附表等
- **8 个分层匹配模块**：参数名 / 单位 / 数值区间 / 符号 / 设备号 / 程序号 / 步骤号 / 归属，各自独立可回归
- **版式注册表**可单独开关某种版式，停用只改 `enabled`，不动代码
- **右侧 PDF 原图面板**：双击明细行直接在右侧扩出整条原图，点格子选取、显示提取结果
- **整页标出所有识别到的表**（3.5）：认出来的每张表画红虚线框，当前那张叠实线；没框处＝没有表或没认出来
- **多选钉格**（3.5）：按住 ⌘ / Ctrl 连选多格，按钮变「钉住 N 格」
- **来源坐标**（3.5）：每条记录带表 bbox / 行号 / 列号 / 逻辑块号，可追溯
- **工具只读**，不修改任何源文件

## 脱敏说明（重要）

本仓库为公开发布，已对源码做以下替换，**代码逻辑未改动**：

| 原内容 | 替换为 |
|---|---|
| 真实 WI 文档编号（44 个） | `WI-0001` ~ `WI-0044` |
| 真实图纸编号（14 个） | `DWG-0000001` ~ `DWG-0000014` |
| 产品家族名（7 个） | `产品线A` ~ `产品线G` |
| 客户方名称、企业全称 | `客户方` / `某医疗器械公司` |
| 默认预填的真实文件名 | 置空（需自己浏览选择） |
| 本机绝对路径 | `~/Desktop/` |
| 内网地址、DHR 号 | `192.168.0.1` / `DHR-0001` |

**副作用**：`app/engine/wi_core.py` 里识别产品线的那组名字现在是占位符，遇到真实文档时不会命中产品线判据。其余逻辑不受影响。

## 已知边界

- 只覆盖这 10 种版式；遇到没见过的新模板识别率明显下降，先跑「表目录」看「读懂率」，低于阈值先补版式再谈判定
- Excel 侧按列名语义定位、不写死列号，但写法差异大时仍需人工核
- 转曲 / 图片区靠 OCR 兜底，属「提示器」，标出来的每条都要人工看
